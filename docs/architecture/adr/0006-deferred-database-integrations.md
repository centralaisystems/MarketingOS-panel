# ADR 0006 — Deferred database and integrations

## Status

Accepted (Phase 1)

## Decision

No Supabase migrations or production integrations in Phase 1. See `data-model-v1.md` for deferred tables.

External research, publishing, ads, analytics, and CRM connectors are deferred to Phases 3–8.

## Consequences

A03 works from local evidence and emits `research_requirements` instead of fetching the web.
